# 8-Bit-5-Stage-RISC-CPU-with-ADC-Timer
An 8-bit System-on-Chip (SoC) featuring a custom 5-stage pipelined RISC CPU integrated with a Timer and SAR ADC controller via an Advanced Peripheral Bus (APB) interface. Developed in Verilog and verified using a Universal Verification Methodology (UVM) testbench in SystemVerilog.
